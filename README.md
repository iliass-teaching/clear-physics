# Clear Physics

A Cambridge IGCSE Physics (0625) course in simple English, for students whose first language is not English.

Website: https://iliass-teaching.github.io/clear-physics/

## Contents

- 136 lessons in 18 units, following the 2026–2028 syllabus (Core and Extended)
- In each lesson: goals, key words, explanations, worked examples, an activity, practice questions, a short quiz and teacher notes
- Online practice questions with new numbers each time
- 17 simulations (motion, waves, light, circuits, magnetism, radioactivity, etc.)
- Printable worksheets, with a different version for each student and the answers
- A list of key words and command words, and a page with the equations to learn

## Running it locally

The site is built with [Astro](https://astro.build/). Node.js 24 is used for the build.

```
npm install
npm run dev
```

Then open http://localhost:4321/clear-physics/

`npm run build` creates the static site in `dist/`.
