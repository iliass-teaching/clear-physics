<Step kind="learn" title="Solid friction" minutes={10}>

**Friction** is a force between two surfaces that touch. It acts **against** the motion (or against the start of motion).

- Friction can **stop** an object moving, or **slow it down**.
- Friction **produces heating**: the surfaces get warm, like your hands in the starter.
- Rough surfaces, and surfaces pressed hard together, give more friction.

<div class="table-wrap">

| Friction is useful | Friction is a problem |
|---|---|
| tyres grip the road | moving parts in machines wear out |
| brakes stop a bicycle | engines get hot and waste energy |
| shoes grip the floor | a heavy box is hard to push |

</div>

We can reduce friction with oil or grease (**lubrication**), or with wheels and smooth surfaces.

</Step>

<Step kind="learn" title="Drag" minutes={8}>

**Drag** is friction on an object that moves through a **fluid** (a liquid or a gas).

- In a **liquid**: a swimmer or a boat feels drag from the water.
- In a **gas**: a cyclist or a car feels drag from the air. Drag in air is **air resistance**.

Drag gets **bigger** when the speed gets bigger. (Remember terminal velocity in Unit 1.)

A **streamlined** shape (smooth and pointed, like a fish or a racing car) reduces drag.

</Step>

<Step kind="do" title="Investigate friction" minutes={17}>

**Equipment:** a wooden block with a hook, a force meter (0–10 N), different surfaces (wood bench, sandpaper, carpet, plastic sheet), masses.

1. Put the block on a surface. Pull it slowly with the force meter.
2. Read the force **just as the block starts to move**. This is the friction force.
3. Repeat 3 times. Find the mean.
4. Repeat on each surface.
5. Then add 500 g on top of the block and repeat on one surface.

| surface | friction 1 / N | friction 2 / N | friction 3 / N | mean / N |
|---|---|---|---|---|
| wood | | | | |
| sandpaper | | | | |
| carpet | | | | |
| plastic | | | | |

</div>

**Questions:**

1. Which surface gives the most friction? The least?
2. What happens to the friction when you add mass on the block?
3. Touch the surface after pulling the block on sandpaper many times. What do you notice?

</Step>

<Step kind="teacher" title="Teacher notes">

**Timing:** starter 5 min, learn 18 min, investigation 17 min, check 15 min, exit ticket 5 min.

**Common mistakes:**

- "Friction always slows things down." Friction can also make motion possible: without friction we cannot walk.
- Thinking air resistance is not a kind of friction (the syllabus calls it friction/drag).
- Drawing friction in the direction of motion.

**Investigation:** the force just as the block starts to move is the maximum static friction. More mass on the block gives more friction (bigger contact force).

**Language support:**

- *Fluid* means a liquid or a gas (not only a liquid, as in everyday English).

**Differentiation:**

- Support: give the results table already drawn.
- Stretch: plot friction force against the total weight of the block. What is the shape of the graph?

**Safety:** sandpaper can scratch skin. Keep masses away from the edge of the bench.

</Step>
