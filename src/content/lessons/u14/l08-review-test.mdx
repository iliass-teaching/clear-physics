<div class="table-wrap">

| | Series | Parallel |
|---|---|---|
| current | the same everywhere | splits: $I = I_1 + I_2$ (junction rule, E) |
| p.d. | shared: $V = V_1 + V_2$ (E) | the same across each branch (E) |
| resistance | $R = R_1 + R_2$ | smaller than each; $\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$ (E) |
| one lamp breaks | everything stops | the others stay on |

</div>

- **Sensors:** thermistor (NTC): hotter → lower resistance. LDR: brighter → lower resistance.
- **Potential divider (E):** $\dfrac{R_1}{R_2} = \dfrac{V_1}{V_2}$.
- **Safety:** live, neutral, earth; switch and fuse in the live wire; earth the metal case or use double insulation; choose the fuse just above the normal current.

</Step>
