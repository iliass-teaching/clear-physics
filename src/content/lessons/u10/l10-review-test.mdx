| Topic | Key ideas |
|---|---|
| reflection | $i = r$, angles from the **normal** |
| plane mirror image | same size, same distance behind the mirror, virtual |
| refraction | change of speed; air → glass: towards the normal |
| refractive index (E) | $n = \dfrac{\sin i}{\sin r}$; $n$ = speed in air ÷ speed in material |
| total internal reflection | glass → air, $i$ bigger than the critical angle; $n = \dfrac{1}{\sin c}$ (E); optical fibres (E) |
| lenses | converging: parallel rays meet at F; diverging: they spread as if from F |
| ray diagrams | parallel → through F; through centre → straight; through F → parallel |
| images | enlarged / same size / diminished; upright / inverted; real / virtual |
| magnifying glass (E) | object closer than F: virtual, upright, enlarged |
| sight (E) | short sight → diverging lens; long sight → converging lens |
| dispersion | prism: violet refracts most; ROYGBIV; red = longest λ, lowest $f$ |
